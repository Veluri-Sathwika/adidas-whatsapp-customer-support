# Adidas WhatsApp Customer Support Chatbot

## Project Overview
This project focuses on a WhatsApp-based customer support chatbot for Adidas, with supporting datasets for inventory, orders, and customer support tickets.

## Repository Contents
- `Inventory.csv` — Inventory-related data.
- `Orders.csv` — Order-related data.
- `Tickets.csv` — Customer support ticket data.
- `system-prompt-alex.pdf` — System prompt documentation.

## Objectives
- Organize inventory, order, and support ticket information.
- Explore how customer support workflows can be supported by chatbot automation.
- Understand the use of structured datasets in customer service applications.

## Technologies
- n8n workflow automation
- WhatsApp integration (as intended by the project)
- CSV datasets
